Questo capitolo descrive l'installazione e la configurazione specifiche del sistema SAP HANA BM1 utilizzato per la documentazione di questa soluzione. Il sistema HANA QM1 è stato implementato allo stesso modo.

Ulteriori informazioni generiche sull'implementazione e le best practice sono disponibili https://docs.netapp.com/us-en/netapp-solutions-sap/bp/hana-asa-fc-introduction.html["SAP HANA su sistemi NetApp ASA con protocollo Fibre Channel"].

[[hana-host-configuration]]
== Configurazione host HANA

Prima di configurare l'host, è necessario scaricare le utilità host SAN NetApp dal sito  http://mysupport.netapp.com/["Supporto NetApp"] e installarle sui server HANA. La documentazione delle utilità host include informazioni sul software aggiuntivo che devi installare a seconda dell'HBA FCP utilizzato.

Le NetApp SAN host utilities possono essere utilizzate anche per ottenere il WWPN degli adattatori host necessari per configurare la mappatura host sul sistema storage.

....
sapcc-hana-tst-02:~ # sanlun fcp show adapter
host20             WWPN:100070b7e40bbadb
host21             WWPN:100070b7e40bbadc
....

[[hana-installation]]
=== Installazione HANA

Ora è possibile eseguire l'installazione HANA.


NOTE: Con la configurazione descritta, la directory /usr/sap/BM1 verrà memorizzata sul disco del sistema operativo. Se /usr/sap/BM1 deve essere memorizzata su un disco separato, è necessario configurare un LUN aggiuntivo sul sistema storage.
